01 / GAME TOOLS + DATA Live platform

PvZH Vault

I built a platform for a game I love. More than 22,000 people have used it.

PvZH Vault is an independent hub for Plants vs. Zombies Heroes. I collected and cleaned raw deck and card data, then built the tools around it: deck discovery, automatic deck building, screenshot recognition, player-facing statistics, and community features.

The interesting part wasn't any single feature. It was making the data, algorithms, and user experience work together as one product that players keep coming back to.
